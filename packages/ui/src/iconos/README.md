# Iconos propios

Coloca aquí los iconos reutilizables del sistema visual.

- SVG: preferido para iconos de interfaz.
- PNG/WebP: para ilustraciones o recursos que necesiten raster.
- Usa nombres en minúsculas y con guiones, por ejemplo `favorito.svg`.

Cuando se entreguen los archivos, se pueden integrar como componentes de UI o
como recursos estáticos según el uso.
